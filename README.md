# ДОМАТЕК — 3D-конфигуратор модульных бань

Конфигуратор для [domatek54.ru](https://domatek54.ru): два проекта модульных бань линейки «Север»
с детальными параметрическими моделями, PBR-материалами, расчётом стоимости и заявкой.

## Проекты

| Проект | Описание | Площадь | Базовая цена* |
|---|---|---|---|
| **Север** | Два модуля 2,4 × 6 м под углом, терраса 13,7 м² во внутреннем углу, панорамное остекление комнаты отдыха, топка печи с террасы | 28,8 м² | от 599 000 ₽ |
| **Север Мини** | Один модуль 3 × 6 м с утопленным крытым крыльцом, панорамное окно, дровник-цоколь | 15,1 м² | 1 560 000 ₽ |

Модели построены по референс-фото заказчика (профлист/планкен графит + сосна, топка печи с улицы,
открытые сваи или поленница по периметру).

\* **Цены ориентировочные.** Базовая цена «Севера» — от 599 000 ₽, как на сайте; цена «Север Мини»
и цены опций ещё не сверены с прайсом. Перед показом клиенту сверьте их с прайсом и выставьте
`PRICES_VERIFIED = true` в `src/data/company.ts` — тогда исчезнет пометка «Цены ориентировочные».

## Что умеет

- Выбор проекта, отделка фасада (сосна / лиственница / термососна, горизонтальная или вертикальная раскладка),
  акцент (профлист с настоящими рёбрами или окрашенный планкен) в 4 цветах RAL.
- Окна и двери: цвет профиля, тип стеклопакета.
- Терраса и участок: настил (сосна, лиственница, ДПК), навес, расширенная терраса, цоколь
  (сваи / дровник / профлист), уличная мебель.
- Парная: печь (дровяная с панорамным стеклом / классическая / электрокаменка), порода полков, LED-подсветка, гималайская соль.
- Комплектация, утепление, доставка с расчётом по километрам.
- Режимы «День / Вечер» (HDRI-небо с привязанным к нему солнцем, подсветка фасада, живой огонь в топке, дым из трубы).
- Ракурсы, автовращение, снимок в PNG ×2, ссылка на конфигурацию (всё состояние — в `#hash`),
  смета с планировкой и печатью в PDF, форма заявки.

## Реализм

- Каждая доска обшивки — отдельная геометрия с фасками, зазорами, разбежкой стыков и подрезкой у проёмов.
- Профлист — реальный трапециевидный профиль (С20), окна — коробка, створка, стеклопакет, откосы, отливы.
- Процедурные PBR-текстуры 2K (цвет / нормали / шероховатость), генератор: `tools/gen_textures.py`
  (сосна с «соборным» рисунком годичных колец и сучками, лиственница, термодерево, графит, древесина полков,
  ДПК, торцы дров, гравий).
- Тени 4K, GTAO (ambient occlusion), bloom, MSAA, тонмаппинг Khronos PBR Neutral.
- Окружение: инстансная трава с ветром, кусты/папоротники/камни (Poly Haven, CC0), процедурные берёзы и сосны (ez-tree), озеро.

## Структура

```
src/data/projects.ts   проекты: стены, проёмы, помещения, терраса, печь, базовая цена
src/data/catalog.ts    опции конфигуратора и правила цен
src/data/company.ts    реквизиты, телефон, endpoint заявок, флаг проверенных цен
src/core/              состояние, URL-сериализация, расчёт стоимости
src/scene/house/       сборка модели: стены, проёмы, кровля, основание и терраса, интерьер, экстерьерные опции
src/scene/landscape.ts участок, трава, растения, деревья, озеро
src/scene/engine.ts    рендер, небо/солнце, постобработка, камеры
src/ui/                панель, смета, заявка, план-схема
```

Новый проект добавляется описанием в `projects.ts` (контур стен с проёмами, помещения, терраса) — модель,
план и смета строятся автоматически.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ (относительные пути — можно положить в любую папку сайта)
```

`?q=low` / `?q=high` — принудительное качество графики (по умолчанию «low» на мобильных).

## Что подключить для продакшена

- Телефон и `requestEndpoint` (приём заявок JSON-ом) в `src/data/company.ts`, ссылку на политику ПДн.
- Реальные цены и, при необходимости, проекты из каталога компании.
- Workflow `.github/workflows/cloudflare-pages.yml` публикует сборку на Cloudflare Pages (`*.pages.dev`)
  при пуше в `main` или вручную (Actions → Deploy to Cloudflare Pages → Run workflow).
  Один раз нужно:
  1. В Cloudflare: Workers & Pages → Create → Pages → Direct Upload, создать проект `domatek`
     (сайт будет на `https://domatek.pages.dev`). Другое имя проекта укажите в переменной
     репозитория `CLOUDFLARE_PROJECT_NAME`.
  2. Создать API-токен с правом *Account → Cloudflare Pages → Edit* (My Profile → API Tokens).
  3. В GitHub: Settings → Secrets and variables → Actions добавить секреты `CLOUDFLARE_API_TOKEN`
     и `CLOUDFLARE_ACCOUNT_ID` (ID аккаунта — в правой колонке на главной странице Cloudflare).
  4. В настройках репозитория отключить GitHub Pages (Settings → Pages), если он был включён.

## Лицензии ассетов

HDRI, текстуры травы/камня/бетона и модели растений — Poly Haven (CC0); кора и деревья — ez-tree (MIT);
нормали воды — three.js examples (MIT); остальные текстуры сгенерированы `tools/gen_textures.py`.
